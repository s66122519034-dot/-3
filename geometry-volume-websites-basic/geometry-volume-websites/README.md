# Geometry Volume Calculator

This project has 10 small web pages for calculating volumes.

## How to use
1. Open the main `index.html` in a browser.
2. Choose one shape.
3. Enter numbers and choose cm or mm.
4. Click Calculate to see the volume in cm³.

Each shape folder has:
- `index.html` (page)
- `styles.css` (page style)
- `script.js` (calculation)
- `asset/` (pictures)

The pages show one column on small screens and three columns starting at 576 px.

For example: Cylinder radius 5 cm, height 10 cm = 785.40 cm³.
Cylinder radius 20 mm, height 50 mm = 62.83 cm³.

Cylinder photo source: Pixabay (link shown on the cylinder page).
